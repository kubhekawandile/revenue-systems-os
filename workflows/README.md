# Northstar Intake Rescue — L1 Day 4

This folder contains sanitised n8n workflow exports for the Northstar lead-intake and runtime-error alerting exercise.

- `intake-v4.json` — lead intake, validation, duplicate suppression and operational logging.
- `error-alert-v1.json` — runtime error notification and failure logging.

Export date: 2026-11-04

Secrets are not included. Credential values must be configured locally in n8n. Instance-specific identifiers and personal addresses have been removed or replaced with placeholders.
